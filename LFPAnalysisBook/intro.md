# LFPAnalysis Book

This book is the canonical onboarding path for `LFPAnalysis`.

It is written for readers who may be new to Python, MNE, or intracranial electrophysiology workflows. The goal is to help you move from raw files to trustworthy analysis objects with as few hidden lab assumptions as possible.

## What you will learn

- how to install the package and its optional analysis extras
- which inputs the workflow expects and which outputs it produces
- how to choose a reference strategy, baseline strategy, and artifact policy
- how to run smoke tests against bundled sample data before analyzing a real dataset
- where to drop down from the stable workflow API into advanced utility modules

## Recommended reading order

1. Installation
2. Data model
3. Quickstart
4. Reference, artifact, and baseline chapters
5. Domain-specific analysis chapters such as PSD, TFR, connectivity, and statistics
